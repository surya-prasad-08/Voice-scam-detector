# Voice Scam Detector

A voice-based system for analyzing suspicious scam-call terms and generating a scam risk score.

## Features

- Analyzes suspicious words or voice/audio input
- Identifies common scam-related patterns
- Generates a scam risk score from 1–200
- Simple and beginner-friendly interface

## Technologies

- Python
- Speech/Voice Processing
- Pattern Analysis
- GUI / Web Interface

## How It Works

1. User provides suspicious words or voice/audio.
2. The system analyzes the input.
3. Scam-related patterns are detected.
4. A risk score is generated.
5. The result is displayed to the user.

## Project Status

Currently under development.
